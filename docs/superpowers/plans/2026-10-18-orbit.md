# Orbit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Orbit, a native macOS menu bar app. You drag files, press a modifier, and drop the files on a slice of a glass wheel. Orbit converts, edits or hands them off, and saves the result beside the original.

**Architecture:**
- **One SwiftPM package with two targets:**
  - `OrbitCore` is a UI-free library holding every rule and every file operation. It is fully unit-tested with Swift Testing against fixture files the tests generate themselves.
  - `OrbitApp` is the executable holding the AppKit/SwiftUI shell: menu bar, trigger detection, wheel overlay, progress and toasts, editors, and Settings.
- **How a drop becomes a file:** each wheel slice is a `SliceAction`. A drop becomes a `JobRequest`, which `JobRunner` routes to the first `Processor` that can handle it. `JobRunner` owns output naming, batching, progress, cleanup and undo.
- **Packaging:** a shell script wraps the SwiftPM binary into `Orbit.app`.

**Tech Stack:**
- Swift 6.3 toolchain, `swift-tools-version: 6.0`, Swift 5 language mode.
- AppKit and SwiftUI.
- Processing: ImageIO, Core Image, Vision, AVFoundation, VideoToolbox, AudioToolbox, PDFKit, QuickLookThumbnailing.
- Swift Testing.
- `libwebp` 1.6.0 via `https://github.com/SDWebImage/libwebp-Xcode`.
- External programs, run without a shell:
  - Homebrew `ffmpeg`
  - `/usr/bin/tar` (libarchive 3.7)
  - `/usr/bin/ditto`, `/usr/bin/zip`, `/usr/bin/unzip`, `/usr/bin/gunzip`
  - `/usr/bin/osascript`

**Spec:** `docs/superpowers/specs/2026-10-18-orbit-design.md`. Every task implements a section of it. Read the section a task cites before starting the task.

## Global Constraints

- Minimum macOS 14.0 (`.macOS(.v14)`, `LSMinimumSystemVersion` 14.0). Use Liquid Glass (`glassEffect`) only behind `if #available(macOS 26, *)`. The fallback is SwiftUI `.ultraThinMaterial`.
- No sandbox, no App Store, no network calls of any kind, no telemetry.
- The trigger needs no Accessibility or Input Monitoring permission. If something proves impossible without one, stop and ask Kevo (spec §8).
- Never modify, overwrite or trash a source file. The single exception is **Move to**, which relocates it. Cleanup only ever trashes URLs that `JobRunner` reserved in the current job.
- Output name is `<stem>-<suffix>.<ext>` in the source's folder. On collision, append `-2`, `-3`, and so on. If the folder isn't writable, use `~/Downloads/Orbit/`.
- At most **10** slices per ring. Overflow goes into a final `MORE` slice.
- The default triggers are:
  - Convert: Shift or ⌘
  - Tools: Shift+⌥ or ⌥⌘
  - Actions: Control
  - The trigger key must be pressed after the drag starts.
- ffmpeg is never bundled. Search for it at the custom path, then `/opt/homebrew/bin/ffmpeg`, then `/usr/local/bin/ffmpeg`. (Putting the custom path first is a deliberate choice: an explicit user choice wins.)
- iWork bundle IDs:
  - Pages: `com.apple.Pages`, then `com.apple.iWork.Pages`
  - Keynote: `com.apple.Keynote`, then `com.apple.iWork.Keynote`
  - Numbers: `com.apple.Numbers`, then `com.apple.iWork.Numbers`
- External programs always receive an argument array, never a shell string. ffmpeg paths are always written as `file:<path>`. AppleScript receives paths through `on run argv`.
- Bundle ID `com.kevo.orbit`. The release build is a universal binary (arm64 + x86_64) with an ad-hoc signature. MIT license. Logs go to `~/Library/Logs/Orbit/orbit.log`.
- No SwiftPM resources in any target. Icons are SF Symbols or drawn in code. `Info.plist` lives in `Support/` and only the build script uses it.
- Every commit message ends with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Kevo's global rules:**
  - Check before writing any path that might already exist.
  - Delete only what this work created.
  - Scripts that write must refuse when the target exists and isn't ours.
- **App tasks need a real drag.** If you can't physically drag in Finder, use the `anthropic-skills:computer-use` skill to drive the Mac. If that isn't available, record the manual checks as pending for Kevo in your report. Don't skip them silently.

## Review Focus

1. **Unsafe filenames.** Names with spaces, quotes, `ü`, or a leading `-` (for example `-rf 'q" ü.mov`) must work with ffmpeg, tar, ditto, zip and osascript, and must never be interpreted as options. Tests: Task 5 and Task 24.
2. **Package directories.** `.rtfd`, `.app`, and package-style `.pages`/`.key`/`.numbers` must be classified as documents (or as `other` for `.app`), never as plain folders. Test: Task 2.
3. **Wrong or missing extensions.** A PNG saved as `photo.jpg`, or a file with no extension, must be classified by its content. Test: Task 2.
4. **One bad file in a batch.** The other files still finish. The failure is reported as `n of m done · k failed`, and no partial output from the failed file remains. Test: Task 8.
5. **Wheel at a screen edge or on a secondary display** (including negative coordinates). The wheel must stay fully on screen. Test: Task 7.

**Interfaces:**
- Produces:
  - `public enum FileCategory: String, Codable, Sendable { case image, video, audio, pdf, document, slides, spreadsheet, subtitle, archive, folder, other }`
  - `public struct DroppedItem: Hashable, Sendable { let url: URL; let type: UTType; let category: FileCategory; let formatKey: String; init(url: URL) }`. `formatKey` is the canonical lowercase extension: `jpeg→jpg`, `heif→heic`, `aif→aiff`, `htm→html`, `markdown→md`, `tar.gz`/`tgz→tgz`, `textClipping→textclipping`. For sniffed content it is the sniffed format.
  - `public enum FileClassifier { static func classify(_ url: URL) -> (type: UTType, category: FileCategory, formatKey: String) }`
  - `public enum OutputFormat: String, CaseIterable, Codable, Sendable` with these cases:
    - `jpg png heic webp tiff avif bmp gif ico pdf`
    - `mp4 mov mkv webm avi wmv`
    - `mp3 m4a aac wav aiff flac ogg opus wma`
    - `docx pages txt md html epub pptx key xlsx csv tsv numbers ods srt vtt`
    - `zip tar tgz`

    It has `var fileExtension: String` (`tgz → "tar.gz"`, otherwise the raw value) and `var label: String` (uppercase raw value, `tgz → "TAR.GZ"`).
  - `public enum MediaSupport` with:
    - `static let ffmpegOnlyRead: Set<String> = ["mkv","webm","avi","wmv","wma"]`
    - `static func needsFFmpegToRead(_ item: DroppedItem) -> Bool`: true when the format is in that set, or when the category is video/audio and `AVURLAsset.audiovisualTypes()` doesn't contain the type.
    - `static let nativeVideoWrite: Set<OutputFormat> = [.mp4, .mov]`
    - `static let nativeAudioWrite: Set<OutputFormat> = [.m4a, .aac, .wav, .aiff, .flac]`
    - `static func isNativelyWritable(formatKey: String) -> Bool`

Classification rules (spec §6.3–6.7):
- **Extension table first:**
  - image: `png jpg jpeg heic heif webp tiff tif bmp gif ico avif svg`
  - video: `mp4 mov m4v mkv webm avi wmv`
  - audio: `mp3 m4a aac wav aif aiff flac ogg opus wma`
  - pdf: `pdf`
  - document: `docx doc pages rtf rtfd txt md markdown html htm textclipping`
  - slides: `pptx ppt key`
  - spreadsheet: `xlsx xls numbers ods csv tsv`
  - subtitle: `srt vtt`
  - archive: `zip tar gz tgz tar.gz rar`
- **Directories:** a non-package directory is `folder`. A package is classified by its extension through the table above (`rtfd`, `pages`, `key`, `numbers`); any other package (such as `.app`) is `other`.
- **Content sniffing** (the first 16 bytes) overrides the extension for regular files:
  - `89 50 4E 47`: png
  - `FF D8 FF`: jpg
  - `GIF8`: gif
  - `%PDF`: pdf
  - `RIFF…WEBP`: webp
  - `RIFF…WAVE`: wav
  - `ftyp` at offset 4: brand `heic`/`heix`/`mif1` is heic, `avif` is avif, `qt  ` is mov, `isom`/`mp41`/`mp42` is mp4, `M4A ` is m4a

  A `PK\x03\x04` header keeps the extension's classification when the extension is zip-based (`docx xlsx pptx epub ods pages key numbers`); otherwise it is zip. Files whose extension is unknown and whose content can't be sniffed are `other`.

**Interfaces:**
- Produces:
  - `public enum OutputNamer`:
    - `static func stem(of: URL) -> String`. Strips `.tar.gz` entirely.
    - `static func uniqueURL(in folder: URL, base: String, ext: String, exists: (URL) -> Bool) -> URL`. Produces `base.ext`, then `base-2.ext`, `base-3.ext`, and so on. An empty `ext` means no dot (used for folders).
    - `static func outputURL(for source: URL, suffix: String, ext: String, in folder: URL, exists: (URL) -> Bool) -> URL`. The base is `<stem>-<suffix>`, or just `<stem>` when the suffix is empty.
    - `static func numberedURLs(for source: URL, suffix: String, ext: String, count: Int, in folder: URL, exists: (URL) -> Bool) -> [URL]`. Each name is `<stem>-<suffix>-<i>`, starting at 1, and each one is made unique.
  - `public enum OutputLocator`:
    - `static var fallbackFolder: URL` (`~/Downloads/Orbit`)
    - `static func folder(for source: URL, fallback: URL = fallbackFolder, isWritable: (URL) -> Bool) -> (url: URL, usedFallback: Bool)`. Creates the fallback folder when it is used.
  - `public func naturalSorted(_ urls: [URL]) -> [URL]`. Uses `localizedStandardCompare` on `lastPathComponent`.
  - `public struct FileMove: Sendable, Equatable { let from: URL; let to: URL }`
  - `public enum UndoRecord: Sendable, Equatable { case trash([URL]); case moveBack([FileMove]) }`
  - `public enum UndoPerformer { static func perform(_ r: UndoRecord, trash: (URL) throws -> Void = { try FileManager.default.trashItem(at: $0, resultingItemURL: nil) }) throws }`. `moveBack` moves `to` back to `from`. If `from` is taken by then, it uses `uniqueURL` in the original folder.

3. Modifiers in `baselineMods` are ignored until they are released.
4. While the wheel is closed and a file drag is active, `bindings.wheel(for: effectiveMods)` must stay non-nil and unchanged for `settleDelay`. Then emit `.open(kind, at: location of that sample)`.
5. While the wheel is open, a different non-nil binding emits `.switchTo` (also after settling). Releasing all modifiers emits nothing.
6. On the button-up edge while open, emit `.close`.
7. `overlayDidClose()` blocks re-opening until the next button-up.
8. When `isEnabled == false`, never emit `.open`.

**`isCombining` is true for:**
- `convert(.pdf)` with more than 1 item, all images
- `tool(.collage)`, `tool(.merge)`, `tool(.join)`
- `action(.archive, _)`
- `convert(zip|tar|tgz)` when the items aren't all archives

**JobRunner rules:**
1. **Units.** A combining action is one unit holding all items in natural order. Anything else is one unit per item, in natural order.
2. **Routing.** Each unit goes to the first processor that can handle it. If none can, throw `.unsupported("Orbit can't do that with this file.")`.
3. **Output folder.** Comes from `OutputLocator.folder(for: firstItemOfUnit, fallback:, isWritable:)`.
4. **When a unit fails** with anything other than `.cancelled`: trash that unit's reserved URLs that now exist, record a `JobFailure(url: first item, message: localizedDescription)`, and continue with the next unit.
5. **On `.cancelled`:** trash every reserved URL that exists from the whole job, then rethrow.
6. **When every unit failed,** throw the first error.
7. **Summary:**
   - With failures: `"<ok> of <n> done · <failed> failed"`.
   - With one unit: `ResultSummary.text(hint, outputs.count)`.
   - With several units that all returned `.sizes`: their before/after sums.
   - Otherwise: `ResultSummary.text(nil, total outputs)`.
8. **Undo.** `.moveBack` records returned by processors are concatenated. Otherwise undo is `.trash(all outputs)`, or nil when there are no outputs.
9. **Clipboard text.** The units' texts joined with `"\n"`.
10. **Progress.** `fraction = (unitIndex + unitFraction) / unitCount`, never decreasing, and ending at exactly 1.

| count | `"3 pages"` |

  - `public enum VideoBitrate { static func plan(durationSeconds: Double, targetBytes: Int64, sourceHeight: Int, hasAudio: Bool) -> VideoBitratePlan? }`. The rules:
    1. `total = targetBytes × 8 × 0.95 / duration / 1000`
    2. `audio = hasAudio ? (total ≥ 1000 ? 128 : 64) : 0`
    3. `video = Int(total) − audio`; if video < 100, return nil
    4. `maxHeight` is 480 when video < 600, 720 when < 1500, 1080 when < 4000. It is nil when it would not be smaller than `sourceHeight`.
  - `public enum VideoTools` (native, AVFoundation), each taking a `progress` callback:
    - `trim(_:range:to:)`
    - `crop(_:rect:to:)`. The rect is in display pixels with the origin at top left, after `preferredTransform`.
    - `speed(_:factor:to:)`. Uses `AVMutableComposition.scaleTimeRange` with `.spectral` pitch. Audio is dropped when the factor is < 0.5 or > 2.
    - `split(_:at:to:)`, where `outputs.count == points.count + 1`
    - `snapshot(_:at:to:)`, saving a PNG with zero-tolerance `AVAssetImageGenerator`
    - `mute(_:to:)`, passthrough without audio tracks
    - `removeMetadata(_:to:)`, passthrough with `metadata = []` and `metadataItemFilter = .forSharing()`
    - `join(_ srcs:to:)`. Passthrough when all sizes match; otherwise re-encoded to the first clip's render size.
    - `compress(_:target:to:) -> Int64`. Uses `AVAssetWriter` with H.264 and `AVVideoAverageBitRateKey`, scaled to `maxHeight`. If the result is larger than the target, it retries at most twice with the bitrate multiplied by target/actual × 0.95, and then throws `.targetTooSmall("Can't fit this video under <bytes>.")`. A tier target is `size × fraction`.
  - `public enum VideoToolsFFmpeg`: the same operations, used when the source needs ffmpeg to read or its format isn't natively writable. The output keeps the source container. Arguments:

    - crop: `-vf crop=w:h:x:y` plus that container's recipe codecs
    - snapshot: `-ss t -frames:v 1`
    - split: repeated trims
    - join: the concat demuxer with a temporary list file
    - compress: `-b:v Nk -maxrate Nk -bufsize 2Nk` plus the container's codecs

      - plain `.gz` (not tar): `gunzip -c` with `stdoutFile`

    - `static func repack(_ archive: DroppedItem, to: OutputFormat, output: URL, temp: URL) async throws`. Extracts to temp, then packs the contents.

    - `.convert(zip|tar|tgz)` as packing (combining), unless every item is an archive, in which case it repacks per item
    - `.action(.archive, .archive(fmt))`, packing
    - `.tool(.extract)`
